# Security reporting / Sicherheitsprobleme melden

Read the application security model before using personal data:
[English](docs/SECURITY.md) · [Deutsch](docs/SICHERHEIT.md).

Only the latest version is maintained. This is a single-user local application;
do not expose its dashboard as a public service.

Report a suspected vulnerability only through GitHub's private vulnerability
reporting: **Security → Report a vulnerability**
(<https://github.com/Valentindghjg/ARGUS/security/advisories/new>). Only the
maintainers can read these reports. If that button is missing, private
reporting is not enabled yet: open a public issue that only asks the
maintainers to enable it, without any details about the problem.
Do not post a public issue containing credentials, real emails, account lists,
private databases or an exploit against a real service. Use a minimal synthetic
reproduction and include the version, environment, impact and reproduction steps.

Sicherheitsprobleme bitte ausschließlich über die private Meldefunktion von GitHub
melden: **Security → Report a vulnerability**
(<https://github.com/Valentindghjg/ARGUS/security/advisories/new>). Nur die
Maintainer können diese Meldungen lesen. Fehlt die Schaltfläche, ist die Funktion
noch nicht aktiviert: Dann ein öffentliches Issue eröffnen, das nur um die
Aktivierung bittet, ohne Details zum Problem. Keine echten Mails, Account-Listen, Passwörter, Tokens oder privaten
Datenbanken in Issues hochladen. Eine künstliche Reproduktion genügt.
