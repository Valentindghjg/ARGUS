            02 / CONNECT READ-ONLY

            Identify your email provider

            For a custom domain, the address alone does not identify your provider. An optional MX lookup gives a clue about the receiving service, but does not automatically identify the correct IMAP host.

            python -m argus_security discover --allow-dns

            The query sends only your mail domain to your DNS resolver. Setup stays offline without this explicit flag.

            python -m argus_security setup-imap

            Verify the host with your provider. Enter credentials only in a hidden terminal prompt. Modern Microsoft or Google mailboxes may require OAuth2 or app passwords.

            python -m argus_security scan-imap --allow-imap

            The scanner opens folders read-only and uses BODY.PEEK. It does not delete or modify emails. This browser interface never asks for credentials.

            03 / OPTIONAL AUTOMATION

            Scheduled read-only IMAP scans

            Store a separate IMAP authorization only in your operating system keyring. No secret is accepted by this dashboard, and scheduled scans run only while ARGUS is open.

            python -m argus_security background-imap enable --interval-minutes 1440

            Use background-imap disable to pause scans, or background-imap revoke to remove the saved authorization from the OS keyring.

            Add another own sign-in address

            Include only addresses you used to register with services. Your Bitwarden account address is not needed. Existing checklists are preserved.

            Your own catalog additions

            Providers you added stay in this profile only. ARGUS checks them like the built-in catalog and never looks them up online.

            How your addresses relate

            A note such as “same mailbox” or “replaced by” helps you review accounts. It never merges accounts or moves a sign-in.

            Where your mailboxes are

            Password resets for your accounts arrive in these mailboxes. Choose the confirmed account that hosts each one; ARGUS then treats it as critical and says why.

            Re-import local email files afterwards. The next explicitly authorized IMAP scan also rechecks older messages for the expanded address scope.
