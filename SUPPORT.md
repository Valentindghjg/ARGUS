# Support / Hilfe

Read the [English guide](README.md) or [deutsche Anleitung](README_DE.md) first.
For setup and behavior questions, use [GitHub Discussions](https://github.com/Valentindghjg/ARGUS/discussions);
if Discussions are not enabled, open an issue with the feature template.
For reproducible defects, open a public issue with synthetic, redacted
information. Use the bug template for defects and the feature template for ideas.

Do not request or share passwords, Bitwarden master passwords, IMAP app passwords,
OAuth tokens, raw personal emails, databases or account inventories. The project
cannot provide account recovery, password changes or security advice for a
specific real account. See [SECURITY.md](SECURITY.md) for vulnerabilities.

Bei Fragen zuerst die englische oder deutsche Anleitung lesen und dann die
[GitHub Discussions](https://github.com/Valentindghjg/ARGUS/discussions) nutzen; sind sie
nicht aktiviert, ein Issue mit der Vorlage für Ideen eröffnen.
Für Fehler nur künstliche, anonymisierte Daten in Issues verwenden. Niemals Passwörter,
IMAP-App-Passwörter, OAuth-Tokens, echte Mails, Datenbanken oder Account-Listen
teilen. Sicherheitslücken stehen in [SECURITY.md](SECURITY.md).
