# Code of Conduct / Verhaltenskodex

Be respectful, practical and privacy-conscious. English and German are welcome.
Harassment, discrimination, threats, personal attacks, doxxing and publication of
anyone’s private data are not acceptable.

This project handles security- and privacy-related topics. Do not post real emails,
account lists, passwords, tokens, IMAP settings, Bitwarden exports or screenshots
that identify another person. Use synthetic, redacted examples. Report security
issues through [SECURITY.md](SECURITY.md), not a public discussion.

Repository maintainers may edit, remove or reject contributions that conflict with
these rules. To report a conduct problem, contact the repository owner privately.

Bitte respektvoll, sachlich und datenschutzbewusst bleiben. Keine persönlichen
Angriffe, Diskriminierung, Drohungen, Doxxing oder privaten Daten veröffentlichen.
Für Fehlerbeispiele ausschließlich künstliche oder sorgfältig anonymisierte Daten
verwenden. Sicherheitsprobleme gehören nach [SECURITY.md](SECURITY.md), nicht in
öffentliche Diskussionen.
