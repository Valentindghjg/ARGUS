No open-source license has been selected for Account Compass yet. Until the
repository owner adds a `LICENSE` file, copyright remains with the owner and
GitHub's terms do not grant permission to copy, redistribute or reuse the
project beyond those terms.

Before making this repository public, the owner should select and add an exact
license text. The publication checklist explains the decision point and common
options: [docs/PUBLISHING.md](docs/PUBLISHING.md).
